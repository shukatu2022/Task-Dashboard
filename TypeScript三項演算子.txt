三項演算子

1. 基本形（文字列の有無で判定）
文字列が入っていれば "yes"、空文字（または undefined や null）なら "no" を返します。

// 1. 変数の定義
const text: string = "hello"; // もし ""（空文字）なら "no" になります

// 2. 三項演算子で判定
const result: string = text ? "yes" : "no";

// 3. 確認
console.log(result); // 出力: "yes"

TypeScript（およびJavaScript）における三項演算子（条件演算子）の基本形は以下の通りです。

TypeScript
条件式 ? 条件がtrueのときの値 : 条件がfalseのときの値;
💡 具体的な使い方
if-else 文を使うよりも、シンプルにコードを1行で書くことができます。

TypeScript
const age: number = 20;

// if-else文の場合
let result1: string;
if (age >= 20) {
  result1 = "大人";
} else {
  result1 = "子供";
}

// 三項演算子の場合（すっきり1行に！）
const result2: string = age >= 20 ? "大人" : "子供";

console.log(result2); // 出力: "大人"

🔍 構造の解説
条件式 (age >= 20)：結果が true または false になる式を書きます。

?：区切り文字です。「この前が条件だよ」という合図です。

値1 ("大人")：条件が true だった場合に返される値です。

:：区切り文字です。

値2 ("子供")：条件が false だった場合に返される値です。

⚠️ 注意点
三項演算子を何重にもネスト（入れ子に）すると、コードが非常に読みづらくなります。複雑な条件分岐は、おとなしく if 文や switch 文を使うのがスマートです。

string ? yes : no でも使える？

string が true なら yes

結論から言うと、そのまま使うことができます！

TypeScript（およびJavaScript）では、string 型の変数（文字列）をそのまま条件式に放り込むと、その文字列が「空文字か、そうでないか」によって true/false が判定されます。

📝 具体的な挙動
TypeScript
const str1: string = "こんにちは";
const result1 = str1 ? "yes" : "no";
console.log(result1); // 出力: "yes" （文字列が入っているので true 扱い）

const str2: string = ""; 
const result2 = str2 ? "yes" : "no";
console.log(result2); // 出力: "no"  （空文字 "" は false 扱い）
💡 知っておくと役立つ仕組み（Truthy と Falsy）
JavaScript/TypeScript には、厳密な boolean型（true/false）以外の一見関係なさそうな値でも、条件式に入れると true や false のように扱われる仕組みがあります。

false 扱いになる文字列（Falsy な値）:

"" （空文字）

true 扱いになる文字列（Truthy な値）:

"" 以外のすべての文字列（スペースだけの " " や "false" という文字列も true になります）


⚠️ TypeScript特有の注意点
もし変数の値が null や undefined になる可能性がある場合（例: string | undefined）、それらも false 扱いとして処理されます。

TypeScript
let username: string | undefined = undefined;
const天国 = username ? "ログイン中" : "ゲスト"; // "ゲスト" になる
文字列が「空っぽじゃないかどうか」をサクッと判定して出し分けたいときには、
非常によく使われる便利な書き方です！

📋 コピペ用テンプレート
1. 基本形（文字列の有無で判定）
文字列が入っていれば "yes"、空文字（または undefined や null）なら "no" を返します。

TypeScript
// 1. 変数の定義
const text: string = "hello"; // もし ""（空文字）なら "no" になります

// 2. 三項演算子で判定
const result: string = text ? "yes" : "no";

// 3. 確認
console.log(result); // 出力: "yes"


2. 関数にして使い回すパターン
実務でよく使う、判定用の共通関数にするパターンです。

/**
 * 文字列が存在するかどうかを判定してテキストを返す
 */
const checkString = (str: string | undefined | null): string => {
  return str ? "yes" : "no";
};

// --- 使用例 ---
console.log(checkString("テキストあり")); // 出力: "yes"
console.log(checkString(""));             // 出力: "no"
console.log(checkString(undefined));      // 出力: "no"


3. JSX / TSX（Reactなど）で使うパターン
フロントエンドの開発（ReactやNext.jsなど）で、画面の表示を切り替える際の定番の書き方です。

// ユーザー名があれば名前を、なければ「ゲスト」を表示する例
const username: string = "たろう";

const UserHeader = () => {
  return (
    <div>
      {username ? <h1>こんにちは、{username}さん</h1> : <h1>ゲストページです</h1>}
    </div>
  );
};
